# P0.1 test fixtures — synthetic, non-medical

`tiny_mul.onnx` is a **synthetic, non-medical** graph generated by
`make_tiny_mul.py` (development-time export only):

- input `image`: float32 `[1, 3, 4, 4]`
- one `Mul` node against a scalar initializer `scale = 2.0`
- output `result`: float32 `[1, 3, 4, 4]`, element-wise `image * 2`

It has no training, no learned weights, no retinal content and no clinical
meaning. It exists solely so the Rust side can prove that manifest
verification, session creation, tensor metadata inspection and inference all
execute. **Passing tests with this file says nothing about HierarchiRetina,
diabetic retinopathy grading, or any accuracy figure.**

Regenerate with:

```bash
ai_engine/.venv/bin/python native/crates/retinacare-ai-bridge/fixtures/make_tiny_mul.py
```

The virtualenv under `ai_engine/.venv/` is git-ignored; Python is used here
for development-time model export only, never in the production runtime.
